## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sakshi-Shetye/digital-galaxy-portfolio.git
   cd digital-galaxy-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build production bundle:**
   ```bash
   npm run build
   ```

## 🌐 Deploy to GitHub Pages (₹0 Cost)

This website is completely free to host on GitHub Pages:

1. **Create a new GitHub repository** named `portfolio` (or `username.github.io`).
2. **If your repository is not the root domain** (e.g. `github.com/Sakshi-Shetye/portfolio`), update `vite.config.ts`:
   ```typescript
   export default defineConfig({
     base: '/portfolio/', // Match your repo name
     // ...
   });
   ```
3. **Push your code to GitHub:**
   ```bash
   git add .
   git commit -m "feat: initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/Sakshi-Shetye/portfolio.git
   git push -u origin main
   ```
4. **Enable GitHub Pages:**
   - In your GitHub repo, go to **Settings** → **Pages**.
   - Under **Build and deployment > Source**, select **GitHub Actions**.
   - Select the **Static HTML** or **Vite** starter workflow.
   - Your site will be live at `https://Sakshi-Shetye.github.io/portfolio/` within 2 minutes!
